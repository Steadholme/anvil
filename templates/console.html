New pipeline

Use one command per line, or the supported steps subset: one name and one run command per step, with an optional block scalar. Commands execute through the system shell inside the Anvil container. Anvil is not a sandbox.

Plaintext warning: the repository locator, branch, and step text are stored without secret masking. Create and update audit events record the repository locator and branch. A failed-run audit event records the pipeline identifier and exit code; an enqueue audit event records only the pipeline identifier. The durable run log records the repository locator and branch, command text, and combined command output; oversized chunks can be truncated. Every operator can read that log. Never put credentials or secrets in the repository locator or step text.
